# Project 1 - Wiki
My Django project for the CS50 Web Programming course!

## Content
Files were mostly added/edited in the *encyclopedia* folder:
- ***templates*** folder: Added html templates.
- ***urls.py***: Added url patterns.
- ***views.py***: Implementation of different views, including Django forms classes for creating a new page or 
editing a page.

Additionally, this readme and a basic .gitignore file were added to the main folder of the repository.
