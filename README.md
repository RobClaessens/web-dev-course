# Project 0 - Search
My first project for the CS50 Web Programming course!

## Content
The most important files within the project are:
- ***index.html***: html page for the basic and "I'm feeling lucky" - Google Search.
- ***image_search.html***: html page for the Google Image Search.
- ***advanced_search.html***: html for the Google Advanced Search.
- ***styles.css***: css containing all styling for the html pages.

Next to these, images of various Google logos and icons were added.
